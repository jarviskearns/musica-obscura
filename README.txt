MUSICA OBSCURA 001 website

Open index.html in a browser to view the site.

For GitHub Pages:
1. Upload the contents of this folder to a repository.
2. Keep index.html, styles.css, script.js, the pages folder, and the assets folder in the same relative positions.
3. In the repository settings, enable GitHub Pages for the branch containing index.html.

The magazine pages are rendered from assets/magazine.pdf into the pages folder.
